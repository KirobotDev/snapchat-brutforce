# Snapchat Automation Test

A Python project built to experiment with web automation, HTTP requests, Selenium WebDriver and JSON data storage.

## Features

- **HTTP Requests** — Check website connectivity using `requests`.
- **Random String Generator** — Generate random alphanumeric combinations.
- **JSON Storage** — Store generated strings in a JSON file using `easyjson`.
- **Web Scraping** — Retrieve page source using Selenium.
- **Form Automation** — Interact with HTML input fields and buttons.
- **WebDriverWait** — Wait for page elements before interacting with them.

## Requirements

- Python 3.10+
- Google Chrome
- ChromeDriver

## Installation

Clone the repository:

```bash
git clone https://github.com/KirobotDev/snapchat-brutforce
cd snapchat-brutforce
```

Install dependencies:

```bash
pip install requests beautifulsoup4 selenium easyjson
```
